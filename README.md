# Sanjay Kumar — Portfolio

A modern, responsive personal portfolio website built with React.js to showcase my experience, technical skills, projects, certifications, and contact information.

## 🌐 Live Portfolio

[View My Portfolio](https://sanjaykumarportfolio.netlify.app)

---

## ✨ Features

- Modern and responsive UI
- Hero section with personal introduction
- About section
- Technical skills categorized by domain
- Professional experience timeline
- Project showcase
- Certifications section
- Contact section
- Responsive footer navigation
- Smooth section-based navigation
- Mobile-friendly design
- Interactive hover effects
- Clean and minimal developer-focused design
